# my-projects
A collection of academic and personal projects I've worked on.

These projects explore different areas of computer science, from data analysis and natural language processing to embedded systems.

Projects

1. COVID-19 News Analysis

Python, Pandas, BeautifulSoup, NLP

A project exploring the relationship between COVID-19 news coverage and reported case trends.

Collected and preprocessed over 1,200 news headlines.

Used TF-IDF to analyze text and transformer-based models for sentiment classification.

Explored how news sentiment varied alongside COVID-19 case data.


2. Humidity Sensor

ESP32, Sensors, Mobile Application

An embedded systems project for monitoring plant soil moisture.

Built a sensor-based system using an ESP32 microcontroller.

Developed a mobile interface using MIT App Inventor to display sensor information.

Integrated data storage and notifications for monitoring moisture conditions.
